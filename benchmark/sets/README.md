# Benchmark instance sets

This directory holds large benchmark instance collections (MIPLIB2017, LP Mittelmann etc).

- `benchmark/sets/miplib2017-benchmark/` — MIPLIB2017 benchmark set (240 .mps.gz), fetched via `uv run python scripts/download_instances.py`
- `benchmark/sets/lp-mittelmann/` — Mittelmann LPfeas/LPopt public subset (49 LPs), fetched via `uv run python scripts/download_lp.py`
- `benchmark/sets/subsets/` — **committed** curated subset lists (fast/super-fast) generated by `scripts/filter_sets.py`
  - `miplib2017-fast-instances.txt` / `miplib2017-super-fast-instances.txt` / `miplib2017-super-small-instances.txt`
  - `lp-mittelmann-fast-instances.txt` (generated after caching LP ground truth)

All `benchmark/sets/*` except `subsets/` and this README are gitignored (see `.gitignore`).
